# ヨミドーパ

青空文庫の**本物の文章だけ**を、「続きを読む」ボタンで1〜2文ずつ読みつづけるスマホ向け読書Webアプリです。
外部サービスを使わない静的サイト(HTML/CSS/JS)で、PWA としてホーム画面に追加できます。

## しくみ

| 場所 | 中身 |
|---|---|
| `source/aozora/` | 青空文庫の原文テキスト(Shift_JIS、図書カードのZIPの中身そのまま。[aozorahack/aozorabunko_text](https://github.com/aozorahack/aozorabunko_text) から取得) |
| `tools/catalog.json` | 収録50作品の一覧、ジャンル、テーマタグ、作者の生没年 |
| `tools/build.py` | 原文 → `docs/data/` を作るスクリプト |
| `tools/verify.mjs` ほか | 検証スクリプト(下記) |
| `docs/` | 公開するサイト本体 |

### 文章の加工(`tools/build.py`)
- Shift_JIS(CP932)から UTF-8 に変換します。
- 冒頭の表題・記号の説明と、末尾の書誌情報(底本: 以降)を取り除きます。
- ルビ `《》`、ルビの開始記号 `｜`、注記 `［＃…］` を取り除きます。注記しかない行(字下げの指定、改ページなど)は行ごと消します。
- 外字 `※［＃…、第3水準1-84-77］` は、注記にある JIS X 0213 の面区点番号か `U+XXXX` をもとに Unicode の文字に置き換えます。番号がなく置き換えられない外字をふくむ作品は収録しません(そのため『山羊の歌』のかわりに『在りし日の歌』を収録しています)。
- くの字点 `／＼` `／″＼` は `〳〵` `〴〵` に置き換えます。
- これら以外の文字は一字も変えません。

### 検証
```sh
npm test          # 外字表の検証 + 全チャンクの照合(Node と Python だけで動きます)
npm run test:e2e  # 実際のブラウザで400回押して、画面に出た文章を照合(Playwright が必要)
```
- `tools/original.mjs` が、build.py とは**別の実装で**原文を読み解きます。
- `tools/verify.mjs` は、アプリと同じ `docs/engine.js` で全50作品をチャンクに分け、**全チャンク(6,891個)が原文の部分文字列と一致すること**、チャンクのあいだで1字も読み飛ばしていないこと、似た作品カードの文章も原文どおりであること、豆知識の根拠が原文末尾の書誌にあることを確かめます。比べるときに許す違いは空行の数だけです。
- `tools/verify_gaiji.py` は、外字の置き換え表を build.py とは別の方法(Shift_JIS-2004 経由)で確かめます。
- `tools/e2e.cjs` は iPhone の画面サイズのブラウザでボタンを押しつづけ、画面に出た本文とカードを原文と照らし合わせます。ボタンが「続きを読む」1つだけであること、「ガチャ」などの説明文や偽の統計が出ていないことも確かめます。

## 機能
- ボタンは「続きを読む」だけです。押すたびに、いま読んでいる作品の続きを1〜2文出します(短い文や詩の行は2つまとめます)。
- 作品を読み終えたら、まだ読み終えていない作品の中でいちばん似ている作品の冒頭へ自動でつなぎます。作品ごとの読書位置は端末(localStorage)に保存します。
- 押すたびに 40% で 📜豆知識、残りで 🎁似た作品 のカードが本文の下に出ます。似た作品カードには、その作品の続き(未読なら冒頭)の1〜2文が出ます。タップするとその作品に移り、カードの文章のつづきから読めます。本文の流れには別の作品の文章を混ぜません。
- 似ている度合い = テーマタグの重なりの数 + 同じ作者なら2。似た作品は似ている度合いで重みをつけて選び、レア度は似ている度合いで決めます(1〜2: ★、3〜4: ★★、5以上: ★★★)。演出は紙吹雪とバイブだけです(iPhone の Safari はバイブ非対応)。
- 豆知識は、原文末尾の書誌(青空文庫の図書カードと同じ内容: 初出・底本・底本の親本・ファイル作成日)と、作者の生没年から作った文だけです。作者の年齢は初出の日付と生年月日から計算します。
- 🔔 通知は、この端末での本当の記録(押した回数、読んだ文字数、読み終えた作品、はじめて読む作者)をもとに読書をほめるものだけです。順位や他人の反応は出しません。連続日数、レベル、XP はありません。

### 注意
- 作者の生没年(`tools/catalog.json` の `authors`)だけは、作業環境から青空文庫のサイトに接続できなかったため手で入力しています。青空文庫の作家別ページ(例: https://www.aozora.gr.jp/index_pages/person81.html )の「生年」「没年」と照らし合わせて確認してください。
- 収録作品はいずれも著作権の保護期間が終わった作品です。原文は「[青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)」にしたがって利用しています。

## 作品を足すには
1. aozorabunko_text から原文の .txt を `source/aozora/<作家ID>/files/...` に置く
2. `tools/catalog.json` に `file` `genre` `tags` を足す(新しい作者なら `authors` にも)
3. `npm run build && npm test`

## 公開のしかた

### Netlify Drop(いちばん簡単)
1. https://app.netlify.com/drop を開く(無料アカウントでログイン)
2. このリポジトリの **`docs` フォルダ** をそのままブラウザにドラッグ&ドロップ
3. 数秒で `https://○○○.netlify.app` のURLが発行されます。サイト名は「Site configuration」で変えられます
4. 更新するときは、同じサイトの「Deploys」画面に `docs` フォルダをもう一度ドロップ

### GitHub Pages
1. このブランチを `main` にマージ(または Pages の公開元にこのブランチを指定)
2. GitHub のリポジトリで **Settings → Pages**
3. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を `main`、フォルダを **`/docs`** にして Save
4. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます

(どちらも HTTPS で配信されるので、サービスワーカーが動き、一度読んだ作品はオフラインでも読めます。)

### iPhone のホーム画面に追加
Safari で公開URLを開く → 共有ボタン → 「ホーム画面に追加」。
